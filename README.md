# 2026 안산시 대학SDGs포럼 모바일 초대장

세로 스크롤형 1페이지 모바일 웹 초대장입니다. 서버·빌드 없이 정적 파일만으로 동작합니다.

## 구성

```
index.html      화면 뼈대 (수정 불필요)
styles.css      디자인 (보라·흰색, 원색 SDGs 심볼)
script.js       화면 생성·동작 (수정 불필요)
content.js      문구·프로그램·링크·음원 설정 ← 여기만 수정
assets/
  sdg-wheel.webp      메인 SDGs 심볼 이미지
  poster.webp / poster-thumb.webp   최종 웹포스터 (확대 보기용)
  og-image.jpg        카카오톡·SNS 미리보기 (1200×630)
  logos/              주최·주관·참여 대학 로고 7종
```

## 실행

- 간단 확인: `index.html` 더블클릭 (단, 공유·주소 복사는 https 배포 주소가 있어야 동작)
- 로컬 서버: 이 폴더에서 `python -m http.server 8765` → http://localhost:8765/

## 내용 수정 방법 (`content.js`)

| 바꾸려는 것 | 위치 |
|---|---|
| 일시·장소·호실 | `event` |
| 모시는 글 · 공동 초청 명의 · 문의 전화 | `greeting` |
| 발표자·직함 | `program[].items[].speaker` (비우면 표시 안 함) |
| 참가신청 URL | `apply.registrationUrl` (비우면 버튼 비활성) |
| 지도 링크 · 주소 · 교통 · 주차 | `location` (비운 항목은 표시 안 함) |
| 배경음악 | `bgm: ['assets/bgm.mp3']` (비우면 버튼 숨김) |
| 공유 주소 · 카카오 키 · 공유 이미지 | `share` |

`content.js` 의 빈 값은 **미확정 값**이므로 추정해서 채우지 마세요.

## 공개 전 확인 체크리스트

1. **참가신청 URL** — 포스터 QR의 신청처와 동일한지 확인 후 `apply.registrationUrl` 입력
2. **호실 표기** — 포스터 `B3호` / 작업지시서 `B33호` 불일치. 확정 후 `event.room` 수정
3. **발표자·직함·주제** — 최종 포스터 대비 교정 후 `speaker` 입력 (포스터에 `000(발표자)`, `미팅 후 결정` 표기 있음)
4. **지도** — 성실관 입구 기준 네이버지도·카카오맵·티맵 URL 입력. 현재는 건물명 검색 링크로 연결되며, 티맵 링크는 실제 기기에서 동작 확인 필요
5. **주소·교통·주차** — 확정 안내만 `location` 에 입력
6. **배경음악** — 사용 허가된 음원 전달 후 `bgm` 에 경로 입력
7. **카카오톡 공유**
   - Kakao Developers 에서 JavaScript 키 발급, 허용 도메인에 배포 도메인 등록
   - `share.shareUrl`(https 배포 주소), `share.shareImageUrl`(`og-image.jpg` 의 https 절대 주소), `share.kakaoJsKey` 입력
   - `index.html` 의 `og:url`, `og:image` 를 https 절대 주소로 교체
   - 키가 없으면 휴대폰 공유창(Web Share) 또는 주소 복사로 대체됩니다
8. **로고·심볼 원본** — 현재 이미지는 최종 .ai 시안에서 고해상도로 잘라 낸 것입니다. 분리된 공식 원본(AI/SVG/PNG)을 받으면 `assets/logos/`·`assets/sdg-wheel.webp` 를 교체하세요

## 제외된 기능 (의도적)

발전기금, 추억의 앨범, 카카오톡 채널, 축하 메시지(폼·목록·저장), 회원가입·관리자, 자체 개인정보 수집 폼, 하단 고정 신청 바.
카카오톡 **공유**와 주소 복사는 유지합니다.

## 동작 요약

- 인트로: 2~3초 후 자동 종료, 화면 탭 / Enter / Space / Esc 로 건너뛰기 (움직임 줄이기 설정 시 애니메이션 생략)
- 배경음악: 음원이 있을 때만 버튼 표시, 사용자가 누른 뒤에만 재생, 켜기·끄기 지원
- 포스터 확대: 닫기 버튼 · Esc · 바깥 탭, 이미지 탭으로 확대/축소
- 레이아웃: 본문 최대 폭 460px 중앙 단일열, 360/390/430px 가로 스크롤 없음, 터치 영역 44px 이상
